Update the site (commissioner)

  1. Save the KFC workbook, then load it here. It's read in your browser only — nothing is uploaded.
  2. Check the preview on the other tabs, then click Download league.json.
  3. On GitHub, open the repo's data folder → Add file → Upload files → drop league.json → Commit. The site updates within a minute or two.

league.json carries rosters, salaries, dead cap, ESPN stats, the NBA schedule and the commissioner's matchup log. It never includes the workbook's keeper marks or notes.

Projections: FantasyPros consensus (preseason, fetched 28 Sep 2026). Weekly game counts: Hashtag Basketball. Daily schedule: Fixture Download via the workbook.
